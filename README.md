# Deep Sea Explorer

Deep Sea Explorer 是一个服务器辅助的深海观测系统，支持开发机远程调用模型服务和
服务器本地 GPU 模型执行。

- [服务器部署实施方案](docs/服务器端模型部署以及与开发机端项目连接的实施方案.md)

## 主要目录

```text
assets/demo/              本地演示视频和虚拟摄像头素材
backend/                  迁移期 API 兼容入口
docs/                     当前文档与历史阶段记录
frontend/                 浏览器前端
legacy/backend/           重构前后端参考代码，不参与运行
scripts/                  开发、测试、媒体和服务器脚本
src/deep_sea_explorer/    正式应用代码
tests/                    自动化测试
```
