# 深海海底智能探测系统使用手册

本文只说明系统的启动与停止方法。所有开发机命令均在项目根目录执行：

```text
C:\projects\deep_sea_explorer\deep_sea_explorer
```

## 一、启动系统

### 1. 确认服务器模型服务

通过 SSH 登录服务器：

```bash
ssh linglong@172.17.10.20
```

检查模型服务：

```bash
curl --fail --silent http://127.0.0.1:19000/v1/health
echo
```

如果返回包含 `"status":"ok"` 的 JSON，说明模型服务已经运行，直接输入 `exit` 退出 SSH。

如果无法访问，则执行：

```bash
sudo -u deepsea -H /bin/bash -lc '
set -euo pipefail

ENV=/projects/deep-sea-explorer/envs/model-service

set -a
. /etc/deep-sea-explorer/model-service.env
set +a

export TEMP_DIR="${TEMP_DIR:-${MODEL_TEMP_DIR:-/sevenH/deep-sea-explorer/data/tmp}}"

nohup "$ENV/bin/python" -m deep_sea_explorer.model_service_main \
  > /home/deepsea/s11-model-service.log 2>&1 < /dev/null &

echo "$!" > /home/deepsea/s11-model-service.pid
'
```

等待几秒后再次检查：

```bash
curl --fail --silent http://127.0.0.1:19000/v1/health
echo
exit
```

### 2. 建立 SSH 隧道

在开发机打开第一个 PowerShell 窗口：

```powershell
conda activate deep-sea-explorer-dev
Set-Location "C:\projects\deep_sea_explorer\deep_sea_explorer"

.\scripts\start-model-service-tunnel.ps1 `
  -ServerHost 172.17.10.20 `
  -ServerUser linglong
```

按提示输入 SSH 密码。窗口保持运行，不要关闭。

### 3. 检查远程模型连接

打开第二个 PowerShell 窗口：

```powershell
conda activate deep-sea-explorer-dev
Set-Location "C:\projects\deep_sea_explorer\deep_sea_explorer"

.\scripts\dev.ps1 remote-model-check
```

看到 `Remote model health check succeeded` 后继续。

### 4. 启动主 API

继续在第二个 PowerShell 窗口执行：

```powershell
.\scripts\dev.ps1 api
```

该窗口保持运行。

### 5. 启动语音服务

打开第三个 PowerShell 窗口：

```powershell
conda activate deep-sea-explorer-dev
Set-Location "C:\projects\deep_sea_explorer\deep_sea_explorer"

.\scripts\dev.ps1 speech
```

该窗口保持运行。

### 6. 启动前端

打开第四个 PowerShell 窗口：

```powershell
conda activate deep-sea-explorer-dev
Set-Location "C:\projects\deep_sea_explorer\deep_sea_explorer"

.\scripts\dev.ps1 web
```

该窗口保持运行。

### 7. 使用完整科普视频启动测试浏览器

再打开一个 PowerShell 窗口：

```powershell
conda activate deep-sea-explorer-dev
Set-Location "C:\projects\deep_sea_explorer\deep_sea_explorer"

.\scripts\dev.ps1 video-test -VideoPath ".\assets\demo\deep-sea-demo-camera.y4m"
```

该命令会校验 Y4M 文件，并使用独立测试配置启动 Chrome，避免普通 Chrome 忽略模拟摄像头参数。

看到 `Fake-camera Chrome started successfully` 后，在新打开的浏览器中点击“开始监测”即可开始完整视频测试。

## 二、停止系统

### 1. 停止浏览器测试

关闭用于测试的 Chrome 窗口。

### 2. 停止开发机服务

依次回到以下 PowerShell 窗口并按 `Ctrl+C`：

1. 前端服务窗口；
2. 语音服务窗口；
3. 主 API 窗口；
4. SSH 隧道窗口。

完成后，开发机端系统已停止。

### 3. 按需停止服务器模型服务

日常测试结束后可以让服务器模型服务继续运行，下次启动会更快。

如果需要彻底停止，登录服务器：

```bash
ssh linglong@172.17.10.20
```

执行：

```bash
PID="$(sudo -u deepsea -H cat /home/deepsea/s11-model-service.pid 2>/dev/null || true)"

if [[ "$PID" =~ ^[0-9]+$ ]] && ps -p "$PID" >/dev/null 2>&1; then
  ARGS="$(ps -p "$PID" -o args=)"
  if [[ "$ARGS" == *deep_sea_explorer.model_service_main* ]]; then
    sudo kill "$PID"
    echo "服务器模型服务已停止"
  else
    echo "PID 对应的不是预期模型服务，未执行停止操作"
  fi
else
  echo "模型服务未运行，或 PID 文件已经失效"
fi

exit
```
